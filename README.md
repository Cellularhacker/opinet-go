# opinet-go
산업통상부 관할의 한국석유공사가 제공하는 opinet 서비스의 `유가 정보 API` 를 위한 go module wrapper

- DATA.go.kr의 데이터목록 [검색결과](https://www.data.go.kr/tcs/dss/selectDataSetList.do?dType=&keyword=&org=%ED%95%9C%EA%B5%AD%EC%84%9D%EC%9C%A0%EA%B3%B5%EC%82%AC&orgFilter=%ED%95%9C%EA%B5%AD%EC%84%9D%EC%9C%A0%EA%B3%B5%EC%82%AC&orgFullName=%ED%95%9C%EA%B5%AD%EC%84%9D%EC%9C%A0%EA%B3%B5%EC%82%AC&conditionType=search)
- opinet의 유가 정보 API [메인페이지](https://www.opinet.co.kr/user/custapi/custApiInfo.do)

## 필수사항
**유가 정보 API(혹은 본 module)를 사용하기 위해서는 opinet의 페이지에서 회원가입 후에 API Key를 할당받아야 합니다.**
